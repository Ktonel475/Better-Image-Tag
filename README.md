# Better Image Tagger

Tagging image by just right-clicking and pick desired tags without typing, and manage tag all in one tab.

## Installation

1. Installing this plugin from community plugin
2. Enable the plugin and done. No extra setup needed for this plugin.

## Basic Usage

- Right-click images → Create metadata notes
- Select tags visually from existing tags
- Stores tags, author, and dates in frontmatter (YAML)

## Commands

- `Tag selected image`
- `Rescan vault for existing tags`
- `Open tag manager sidebar`

## Notes

if you accidentally close the tag manager tab, you can reopen in the settings of this plugin.
